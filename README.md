# Контент-завод «Экополис»

Набор для запуска контент-завода ООО «Экополис»: слежение за темой, подготовка материалов, выпуск по расписанию на восемь площадок, приём заявок и разбор результата. Работа ведётся в Codex отдельными сессиями.

**Начать отсюда:** `docs/00-С-ЧЕГО-НАЧАТЬ.md`. Общий план: `МАСТЕР-ПРОМПТ.md`.

## Что внутри

| | |
|---|---|
| `МАСТЕР-ПРОМПТ.md` | решения, площадки, сессии, команды |
| `AGENTS.md` | правила, которые Codex читает сам |
| `prompts/sessions/` | промпты восьми сессий |
| `prompts/samples/` | образцы на каждый вид работы и девять готовых записей |
| `docs/` | бриф, архитектура, доступы, грабли, расписание, редполитика, риски, фактура, план, витрина |
| `legal/` | документы для юриста клиента |
| `src/`, `packages/bot/`, `ops/` | код завода, движок бота, сервер и релей |
| `content/`, `bot/` | статьи сайта, банк тем, канал YouTube; кодовые слова и материалы бота |

## Площадки

Threads, Telegram-канал, ВКонтакте, Дзен, YouTube, Instagram, Rutube, рассылка в боте. Главная видео-площадка — YouTube. Сервисы автопостинга и конструкторы ботов не используются: с площадками работает свой код.

## Три правила, на которых всё держится

1. Без «Одобрить» от человека клиента не выходит ничего.
2. Персональные данные людей не покидают сервер в России.
3. Значение ключа не появляется нигде: ни в выводе, ни в файле проекта, ни в переписке.

Остальные одиннадцать: `AGENTS.md`.

## Что не проверено боем

Публикация рилсов своим кодом, загрузка на Rutube по ключу, фото и видео во ВКонтакте по ключу администратора, вход Threads по ссылке, снятие срока выхода с ролика YouTube при отзыве согласия, сверка оборванной отправки в Telegram-канал. По каждому есть ручной запасной путь. Полный список: `МАСТЕР-ПРОМПТ.md`, раздел 10.

## Чьё это

Код и промпты подготовлены исполнителем для клиента. Серверы, аккаунты, ключи и данные людей принадлежат клиенту. Документы в `legal/` — проекты: их утверждает юрист клиента.
