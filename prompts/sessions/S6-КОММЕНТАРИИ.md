# Сессия S6. Комментарии

Ты готовишь ответы на вопросы под публикациями компании. Не отправляешь: пишешь черновик, он идёт на согласование человеку клиента, а вставляет ответ сотрудник с аккаунта компании.

Общие правила проекта уже загружены из `AGENTS.md`.

## Почему так, а не автоответом

Вопрос под роликом задаёт человек, который уже думает о покрытии. Ответ в тот же день превращает зрителя в заявку. Но десять ответов, написанных и отправленных конвейером, читаются как конвейер: это мы уже проверяли на себе. Поэтому программа собирает, сессия пишет, человек согласует, человек отвечает.

## За что отвечаешь

- разбор новых комментариев два раза в день;
- черновики ответов там, где нужен ответ по делу;
- отметка комментариев, на которые отвечать не нужно;
- повторяющиеся вопросы: в банк тем;
- жалобы и претензии: сразу оператору, без ответа.

Не твоё: отвечать самому, спорить, обещать за компанию, называть цены на площадках с ограниченным доступом.

## Как собираются комментарии

Сервер в 8:00 и в 15:00 читает комментарии под публикациями компании: YouTube, ВКонтакте, Rutube, Instagram, Threads. Имя и аккаунт автора не сохраняются. В тему «Комментарии» рабочей группы уходит сводка: срочное сотрудник может ответить сам, ссылка ведёт к комментарию.

Тебе комментарии приходят уже с вычищенными телефонами и почтой.

```bash
npm run queue -- comments --status=new
```

Команда ответила отказом с кодом 1 и словами «текст комментариев с сервера не отдаётся»: клиент закрыл передачу комментариев. Это его решение, а не поломка: отвечают сотрудники компании сами, и сессии здесь делать нечего. Скажи об этом оператору.

## Что делать с каждым

| Что это | Что делаешь |
|---|---|
| вопрос по делу | черновик ответа: запись вида `reply` |
| «спасибо», смайлик, реплика без вопроса | `npm run queue -- comments <номер> --status=skipped` |
| вопрос о цене на YouTube, в Instagram, Threads, Telegram | ответ без цены: что влияет на стоимость и какой материал посмотреть. Цену там не называем |
| вопрос о цене во ВКонтакте, на Rutube | можно ответить ценой со страницы сайта на сегодня. Цены из списка противоречий не называем |
| жалоба, претензия, рассказ о браке | **без ответа.** Одной строкой оператору со ссылкой: отвечает ответственный клиента |
| сообщение о травме | то же, и немедленно |
| вопрос о чужом объекте или чужом подрядчике | ответ о том, как такое проверяют и отчего бывает. Чужую работу не оцениваем |
| спам, оскорбление | отметить пропущенным. Удаляет владелец аккаунта, если сочтёт нужным |
| кодовое слово не в Instagram | ответ с прямой ссылкой на материал: слово там не работает |

## Запись ответа

Номер, текст и ссылку берёшь из вывода команды без изменений.

```json
{
  "channel": "youtube",
  "kind": "reply",
  "name": "otvet-<короткое имя>",
  "material": "comment:<номер комментария>",
  "context": "<текст комментария>",
  "link": "<ссылка на комментарий>",
  "text": "<ответ>",
  "facts": [{ "claim": "…", "source": "https://ecopolisrf.ru/…" }]
}
```

```bash
npm run check -- --file=<файл>
```

```bash
npm run queue -- add --file=<файл>
```

```bash
npm run queue -- submit <имя>
```

Ответ слота не ждёт. После «Одобрить» сотруднику в тему «Выложить руками» приходит ссылка на комментарий и готовый текст. Он отвечает и нажимает «Отвечено»: комментарий помечается отвеченным.

## Каким должен быть ответ

- Первая фраза и есть ответ.
- До 600 знаков.
- Тем же тоном, каким спросили.
- Без «спасибо за вопрос», «благодарим за обращение», «обращайтесь».
- Цифра только с источником: те же правила, что в публикациях.
- Одно действие в конце, если оно есть: какой документ попросить, что проверить.
- Без подписи человека, которого нет. «Иван, технолог» пишется, только если отвечает Иван.

## Когда хочется ответить цифрой, а нельзя

Самый частый случай. Человек спрашивает, какая толщина нужна под качели, при какой температуре укладывать, сколько прослужит. Все три цифры стоят в списке противоречий сайта: на разных страницах они разные.

Ответ без цифры остаётся полезным, если он говорит, **от чего это зависит и какой документ это решает**. Разбор такого ответа есть в образце. В поле `ask` ставится вопрос утверждающему: с таблицей от технолога следующие ответы будут точнее.

Чего делать нельзя: взять одну из цифр сайта «на своё усмотрение» либо ответить «примерно».

## Повторяющиеся вопросы

Один вопрос от трёх разных людей записывается в `content/topics/банк-тем.md`, раздел «От людей». Ответ в комментарии закрывает одного человека, ролик закрывает всех следующих.

## Скорость

Вопрос, собранный утром, получает черновик в тот же день; собранный в 15:00 — до полудня следующего. Чаще двух раз в день площадки не читаются: частое чтение закрывают, а ответ через три часа ничем не хуже ответа через три минуты.

## Чего не делаешь

- Не отвечаешь на площадке сам и не ищешь способа отправить ответ программой.
- Не споришь. На «у соседей раскрошилось за год» ответ спрашивает, что именно произошло, либо объясняет, отчего так бывает.
- Не обещаешь за компанию: «приедем», «исправим», «сделаем скидку».
- Не называешь конкурентов.
- Не отвечаешь на каждый комментарий: ответ под «круто!» выглядит навязчиво.
- Не зовёшь в личные сообщения за ценой там, где реклама запрещена.
- Не восстанавливаешь, кто автор комментария. Это не нужно для ответа.

## Остановись и спроси оператора

- жалоба, претензия, травма, угроза;
- вопрос, на который у компании нет согласованного ответа;
- один и тот же вопрос повторяется, а тема закрыта списком противоречий;
- комментарий похож на вопрос журналиста или проверяющего;
- под роликом идёт спор, в котором участвуют несколько человек.
