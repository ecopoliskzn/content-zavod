# Образец: название и описание ролика на YouTube

Сессия S2. Готовая запись: `prompts/samples/entries/youtube-vyrubki-do-osnovaniya.json`. Сценарий этого ролика: `prompts/samples/сценарий-ролика.md`.

## Из чего состоит описание

Из двух частей, и пишет их разные руки.

| Часть | Кто пишет | Кто согласует | Где лежит |
|---|---|---|---|
| Текст: первая строка и два–три абзаца | сессия | утверждающий | поле `text` записи |
| Блок под текстом: строка о компании, ссылка на материал, ссылка в бота, хэштеги, серия, соседние ролики, статья | программа | утверждающий видит состав в карточке | поля `goSlug`, `botKey`, `hashtags`, `series`, `article`, `seeAlso` |

Так сделано ради одного: когда выходит следующая часть серии, описание прошлой дополняется ссылкой на неё без нового согласования. Согласованный текст при этом не меняется.

## Название

Называет событие или поступок. Ключевые слова стоят внутри фразы, до 80 знаков.

| Слабо: тема | Держит: событие |
|---|---|
| Контроль толщины резинового покрытия | На пятистах метрах покрытия делают четырнадцать вырубок, и каждую до основания |
| Основание под резиновое покрытие | В школе не стали фрезеровать асфальт: неровности закрыли выравнивающим слоем |
| Как выбрать резиновую крошку | начинается с «как»: проверка укажет, что это тема |

Замер исполнителя: ролик с названием-событием набрал 3 844 просмотра, два соседних ролика той же серии с названиями-темами 926 и 1 057.

Чего в названии нет: «#shorts», «ссылка в описании», заглавных букв подряд, даты, которая протухнет. На канале клиента 129 названий начинаются с «#shorts»: площадка давно определяет короткий ролик сама, по длине и пропорции кадра.

## Текст описания

**Первая строка.** Единственная, которую видно без разворачивания. В ней контекст или обещание и **нет числа из названия**: готовый ответ в первой строке снимает вопрос, ради которого ролик открывают. Это проверяет программа и останавливает запись.

В образце название говорит «четырнадцать вырубок». Первая строка описания говорит о другом: «Толщину резинового покрытия нельзя оценить на глаз».

**Абзацы.** То, чего нет в ролике, либо то, что стоит перечитать: правило целиком, порядок действий, оговорка. Описание не пересказывает ролик.

**Для серии по частям** последним абзацем: «В следующей части: …».

**Хэштегов в тексте нет.** Они лежат в поле `hashtags`, до пяти, без решётки и пробелов.

## Поля записи

```json
{
  "channel": "youtube",
  "kind": "short",
  "name": "vyrubki-do-osnovaniya",
  "title": "…",
  "text": "…",
  "media": [{ "type": "video", "url": "https://…/vyrubki-do-osnovaniya.mp4" }],
  "hashtags": ["резиновоепокрытие", "резиноваякрошка", "детскаяплощадка", "благоустройство", "приемкаработ"],
  "goSlug": "priemka2",
  "goLabel": "Чек-лист приёмки покрытия",
  "botKey": "priemka",
  "botLabel": "Короткий чек-лист в Telegram",
  "article": "priemka",
  "series": "priemka",
  "facts": [{ "claim": "…", "source": "https://ecopolisrf.ru/…" }]
}
```

| Поле | Что значит |
|---|---|
| `kind` | `short` — вертикальный ролик до трёх минут; `video` — обычный |
| `name` | имя записи латиницей до 32 знаков: оно же метка публикации в ссылках |
| `goSlug` | короткая ссылка из `bot/links.json`: главный переход из ролика |
| `botKey` | материал бота из `bot/materials.json`: ссылка в Telegram с меткой `yt-…` |
| `article` | слаг статьи сайта, по которой снят ролик |
| `series` | ключ серии из `content/youtube/series.json` |
| `seeAlso` | номера двух роликов «смотрите также», если автомат подобрал не те |
| `pin` | `false`, если закреплённый комментарий под этим роликом не нужен |
| `event` | `true`, если ролик про событие и дата в описании уместна |

## Что уйдёт на канал

Когда запись уже стоит в очереди, команда показывает описание целиком, ещё до загрузки ролика:

```bash
npm run yt -- --desc --id=vyrubki-do-osnovaniya
```

Для образца получается так:

```text
Толщину резинового покрытия нельзя оценить на глаз: два одинаковых с виду участка могут сильно отличаться по расходу смеси.

Один из надёжных способов проверки: вырезать контрольный участок до основания и измерить слой штангенциркулем. Размер вырубки 10 на 10 сантиметров. На площадке в 200 квадратных метров их делают 5, на каждые следующие 100 метров добавляют по 3. Точку берут не ближе 3 метров от края.

Заказчику резать покрытие самому не нужно. Метод контроля заранее записывают в договор, места измерений согласуют, вырубки делают при обеих сторонах, каждую точку отмечают на схеме и фотографируют. После измерения участок заполняют и уплотняют до общего уровня.

«Экополис» производит и укладывает покрытия из резиновой крошки: детские и спортивные площадки, беговые дорожки. Казань, с 2013 года. Сайт: ecopolisrf.ru
Чек-лист приёмки покрытия: https://go.ecopolisrf.ru/go/priemka2?c=yt&p=vyrubki-do-osnovaniya
Короткий чек-лист в Telegram: https://t.me/ecopolis_help_bot?start=yt-priemka

#резиновоепокрытие #резиноваякрошка #детскаяплощадка #благоустройство #приемкаработ

Статья на сайте: https://go.ecopolisrf.ru/go/priemka?c=yt&p=vyrubki-do-osnovaniya
```

Когда у серии появится плейлист и соседние ролики, под хэштегами встанут строки «Серия …», «Следующая часть …», «Смотрите также …».

## Кодового слова нет

Ни в названии, ни в описании, ни в закреплённом комментарии. На YouTube комментарии бот не читает: человек напишет слово и не получит ничего. Вместо слова стоит прямая ссылка. Проверка остановит запись со словом бота заглавными.

## Закреплённый комментарий

Под каждым роликом: та же ссылка, что в описании, и приглашение задать вопрос. Закрепить комментарий программа не может. В момент выхода ролика в тему «Выложить руками» приходит текст и три шага для сотрудника.

Для образца:

```text
Чек-лист приёмки покрытия: https://go.ecopolisrf.ru/go/priemka2?c=yt&p=vyrubki-do-osnovaniya
Вопросы по своей площадке задавайте здесь: отвечает специалист.
```

## Порядок от записи до канала

1. Файл записи: `content/queue/youtube/<дата>/<имя>.json`.
2. `npm run check -- --file=<файл>`: ноль блокирующих и ноль замечаний.
3. Ролик в хранилище: `npm run media -- --file=<путь к ролику>`. Адрес из вывода ставится в `media`. Отсюда же ролик заберут Rutube и Instagram.
4. `npm run queue -- add --file=<файл>`, затем `npm run queue -- submit <имя>`.
5. Утверждающий нажал «Одобрить».
6. `npm run yt -- --desc --id=<имя>`: посмотреть итог глазами.
7. `npm run yt -- --upload --id=<имя> --file=<путь к ролику>`. Ролик уходит закрытым с датой выхода из слота. YouTube откроет его сам.
8. В слот сервер сверяет, что ролик открылся, и шлёт просьбу закрепить комментарий.
9. После выхода: `npm run yt -- --relink --series=<ключ>`: прошлые ролики серии получают ссылку на новый.

## Тот же ролик на других площадках

| Площадка | Что меняется |
|---|---|
| Rutube, ВКонтакте | своя запись с тем же `title` и `text`. Связей между роликами нет: это номера YouTube. Можно добавить абзац-предложение: площадки открытые |
| Instagram | своя запись вида `reel`, подпись по образцу `prompts/samples/подпись-instagram.md`, файл с финалом про кодовое слово |

## Частые ошибки

- **Число из названия в первой строке.** Самая частая. Программа её остановит.
- **Описание-пересказ.** Тот, кто посмотрел ролик, ничего нового не узнал; тот, кто не смотрел, уже не посмотрит.
- **Хэштеги в тексте.** Блок под текстом собирает программа: хэштеги в тексте окажутся в описании дважды.
- **Дата без пометки.** «Объект сдали 4 сентября» в ролике про событие законно: ставится `event: true`. В остальных роликах дата через год выглядит как запущенность.
