# Образец: новое кодовое слово и материал бота

Сессия S3. Слово заводится редко: на старте их два, и третье стоит выключенным, пока клиент не снял противоречие в цифрах.

## Из чего состоит слово

Из трёх файлов. Слово без любого из них не работает либо работает во вред.

| Файл | Что в нём | Зачем |
|---|---|---|
| `bot/scenarios/<ключ>.json` | само слово, где его слушать, что ответить | Instagram: ответ на слово в комментарии и директе |
| `bot/materials.json` | материал: заголовок, выжимка, ссылка на статью | Telegram-бот: что человек получит, придя по ссылке |
| `bot/links.json` | короткая ссылка на статью | счётчик переходов |

## Когда заводить новое слово

Все три условия сразу.

1. Есть материал, который человек захочет получить: чек-лист, расчёт, памятка. «Подробности» и «консультация» материалом не считаются.
2. В материале нет ни одной цифры из списка противоречий (`docs/09-ФАКТУРА-КЛИЕНТА.md`, раздел 7).
3. Под слово запланировано хотя бы три ролика. Слово на один ролик не окупает своей поддержки.

## Сценарий

Образец: `bot/scenarios/priemka.json`.

```json
{
  "ключ": "priemka",
  "слова": ["ПРИЁМКА", "ПРИЕМКА"],
  "где": ["комментарий", "директ"],
  "максДлина": 40,
  "приоритет": 10,
  "исключения": ["приёмка товара", "приемка товара"],
  "текст": "Здравствуйте! Вы просили чек-лист приёмки резинового покрытия.\n\n…\n\nОткрыть: {ссылка}",
  "публично": "Отправили чек-лист в личные сообщения.",
  "зачем": "Для кого слово, какой страх закрывает, под какие ролики ставится."
}
```

| Поле | Правило |
|---|---|
| `ключ` | латиницей; он же ключ материала и хвост ссылки в бота |
| `слова` | заглавными, по-русски. Слово с «ё» записывается дважды: с «ё» и с «е» |
| `максДлина` | 40. Длинная реплика со словом внутри считается разговором, и бот молчит. Без этого предела бот однажды ответил в чужой разговор |
| `исключения` | обороты, в которых слово значит другое: «расход топлива», «приёмка товара» |
| `текст` | уходит в директ. Что человек просил, что внутри, ссылка. Без цен и без «оставьте заявку» |
| `публично` | короткий ответ под комментарием: другие видят, что слово работает |
| `зачем` | для людей: в программе не участвует, но без него через месяц никто не вспомнит, под что слово |
| `включён` | `false` выключает сценарий, не удаляя его |

**Слово выбирается по трём признакам:** одно слово; не встречается в обычной речи под роликом; называет то, что человек получит. «ПРИЁМКА» годится. «ДА», «ХОЧУ», «ИНФО» ловят случайных людей. «ЦЕНА» и «РАСЧЁТ» превращают публикацию в предложение купить.

## Материал

Образец: запись `priemka` в `bot/materials.json`.

- `teaser`: две фразы, которые человек видит первыми. Что это и зачем ему.
- `summary`: пять–семь пунктов. Каждый самостоятелен: человек, прочитавший только их, уже получил пользу. Каждая цифра есть в статье клиента.
- `note`: откуда взято и чем ограничено.
- `articleUrl`, `goSlug`: куда ведёт кнопка.
- `sources`: адреса статей, из которых взяты цифры.

Материал выдаётся сразу, без вопросов и без формы. Кнопка «Обсудить мой объект» стоит под ним: заявка начинается по желанию человека.

## Порядок

1. Написать материал и сверить каждую цифру по образцу `prompts/samples/фактчек.md`.
2. Добавить слаг статьи в `bot/links.json`.
3. Написать сценарий.
4. Проверить:

   ```bash
   npm run test:bot
   ```

   ```bash
   npm test
   ```

   ```bash
   npm run doctor
   ```

   Доктор проверяет, что слово не повторяется в двух сценариях и что у слова есть материал.
5. Показать текст сценария и материал утверждающему: это слова компании, которые уйдут человеку в личные сообщения. Согласуется сообщением в рабочую группу.
6. Коммит и выкладка на сервер: `bash ops/deploy.sh zavod@<адрес сервера>`. До выкладки бот о новом слове не знает.
7. Живая проверка с постороннего аккаунта: слово под роликом, ответ под комментарием, сообщение в директ, ссылка, материал в боте.
8. Только после этого слово ставится в подпись первого ролика.

## Ссылки в бота для других площадок

Слово работает только в Instagram. Остальным площадкам тот же материал отдаёт прямая ссылка с меткой:

```bash
npm run link -- --bot=priemka --channel=youtube
```

Команда печатает `https://t.me/<бот>?start=yt-priemka`. По метке бот узнаёт, с какой площадки пришёл человек, и заявка запишется этой площадке.

## Тексты бота

Все фразы бота лежат в `bot/texts.json`: приветствие, согласие, благодарность, отказ. Правка любой из них, в которой упомянуты персональные данные или согласие, меняет версию согласия (`consentVersion`) и согласуется с юристом клиента: `legal/09-ТЕКСТЫ-БОТА-И-ФОРМ.md`.

## Чего бот не делает

- Не отвечает на вопросы сам: вопрос уходит в рабочую группу без имени человека, ответ сотрудника возвращается ему от имени бота.
- Не пишет первым тому, кто не писал.
- Не шлёт рассылку без отдельного согласия и чаще двух раз в месяц.
- Не просит телефон до согласия на обработку данных.
- Не отвечает дважды на одно слово от одного человека под одним роликом.

## Частые ошибки

- **Слово без материала.** Бот отвечает общей фразой, человек больше не напишет.
- **Слово-обиход.** «Расход» без исключений ловит «расход топлива» и «расходы на ремонт».
- **Материал-реклама.** Чек-лист, в котором каждый второй пункт «закажите у нас», читают один раз.
- **Слово поставлено в подпись до выкладки.** Ролик вышел, слово пишут, бот молчит.
