# Сроки выпуска во время сдачи

Решение оператора 06.11.2026: до команды «переходим на расписание» в реестре установлен `release.mode=commissioning`.

| Площадка | Если срок не задан оператором |
|---|---|
| Threads | Ближайший технический проход после «Одобрить» |
| Telegram | То же; недоступный канал остаётся ошибкой доступа, а не переносится на завтра |
| ВКонтакте | То же; ручное видео остаётся пакетом до подтверждения выкладки |
| Дзен | Сразу передать согласованный пакет сотруднику; это ещё не опубликовано |
| YouTube | После согласия загрузить закрытым и открыть штатным выпуском; автоматическое завтра не ставится в `publishAt` |
| Instagram | То же; версия ролика с парой YouTube ждёт подтверждённого выхода YouTube, без искусственной минуты и вечерней сетки |
| Rutube | После YouTube, если это один ролик; без ключа — сразу пакет на ручную выкладку |
| Рассылка бота | Ближайший проход после одобрения, только при открытом клиентом приёме и выполненных согласиях |

В этом режиме редакционные `grid`, `slots`, ночные часы, `perDay`, `minGapMin` и пауза догона не удерживают публикации. Ограничения API, проверка содержимого, антидубли, STOP/HOLD, перехват и один исполнитель остаются. Сбой транспорта не требует повторного согласования неизменной публикации.

Явный срок — `timing.mode=at`, период — `period`, задержка — `after-approval` с `delayMin`. Команды `add/move --date=... --time=...`, `--from=... --to=...`, `--delay=...` сохраняют это поручение. Обычные `date/time` из старой автосетки не считаются поручением. `move ID --next` убирает автоматическое ожидание, сохраняя текст, медиа, contentHash и действующее согласие. Для review статус остаётся review. `refresh-card ID` редактирует существующую карточку без повторного фотоальбома.

В `scheduled` редакционные ограничения вновь действуют, ближайшее допустимое окно выбирается с учётом ночи, потолка и паузы. Точный будущий срок не переносится молча при постановке/переносе: конфликт даёт отказ. Согласие на явно заданный срок не заменяет его другим. Кадры Stories одного материала считаются одной серией, а не шестью постами с трёхчасовой паузой.

Отдельные интервалы загрузки, обработки и ограничения частоты запросов площадки сохраняются в адаптерах. «Сразу» означает ближайшее технически возможное исполнение, а не обещание нулевой длительности загрузки.
