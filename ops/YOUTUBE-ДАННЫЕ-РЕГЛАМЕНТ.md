# Порядок работы с данными YouTube

15.10.2026. Обязательный порядок оператора для политики `/youtube-app/privacy/`.

## Каждый месяц, не реже одного раза в 30 дней

- Проверить разрешение владельца штатным `npm run doctor -- --live` на компьютере и сервере. Отказ авторизации и сетевой сбой различать.
- Обновить опись канала и метаданные API либо удалить устаревшие копии по согласованному перечню. Проверить, не удалены ли соответствующие видео. Исторические разрешённые отчёты отмечать датой, не выдавать за текущие цифры.
- Проверить производные копии в витрине, отчётах и истории проекта. Данные API не помещать в новые коммиты; существующие копии учитывать отдельно.
- Зафиксировать дату проверки и результат без значений ключей и переписки людей. Этот регламент выполняется оператором; автоматическая очистка не заявлена.

## Запрос об отключении или удалении

1. Принять обращение по опубликованному контакту, подтвердить полномочия заявителя. Пароли, коды и ключи не запрашивать. Не копировать обращение в сессию Codex.
2. При отключении прекратить обращения API, отозвать refresh token штатным запросом Google и удалить локальные ключи на обеих машинах. Значения не выводить. До необратимого удаления подготовить точный перечень и получить подтверждение оператора.
3. Найти копии данных канала: `content/youtube/`, отчёты, сведения очереди/журнала, витрина, разрешённые снимки, история Git, рабочие карточки Telegram, временные файлы и резервные копии. Не читать `data/leads/`; это другой поток данных. Удаление записей очереди выполнять только её штатными командами.
4. Удалить данные по подтверждённому перечню, включая резервные и исторические копии, как можно скорее и не позднее 7 календарных дней от подтверждённого запроса. Исходные авторские материалы компании отделить от данных API. При юридической обязанности сохранения проверить основание и ограничить использование с юристом клиента.
5. Подтвердить выполнение клиенту. Удаление копий приложения не удаляет видео на YouTube; такие действия требуют отдельного согласованного списка.

При обнаружении отзыва разрешения через настройки Google прекратить обращения и удалить данные API как можно скорее, не позднее 30 календарных дней. Если поступил запрос пользователя, действует срок 7 дней. Сам по себе сетевой таймаут не доказывает отзыв.

Перед запуском регулярных сборов необходимо поставить этот регламент на контроль оператора. Публичная политика устанавливает обязательства, но её публикация не доказывает проверку полного удаления на реальных копиях. Такую проверку проводят отдельно на тестовых данных.
