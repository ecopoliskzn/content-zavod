# Сторож правок: код проверяет, основная модель редактирует

Настроено по поручению оператора 06.11.2026 для экономии вызовов основной модели.

## Рабочая схема

Отдельная локальная задача **«Сторож правок — лёгкая проверка»**, ID `automation-2`, запускается каждые 5 минут на `gpt-6-luna`, reasoning `low`. Это отдельный короткий запуск, не продолжение большой истории основного чата. Прежний heartbeat `instagram-youtube`, который будил основную сессию каждые 5 минут, удалён.

Сторож выполняет `node C:/ecopolis-zavod/ops/review-watch.mjs`. Код сам читает структурированные данные штатного API очереди, фильтрует наблюдаемые записи и сравнивает отпечатки. В stdout только `NO_CHANGE`, `BUSY` либо небольшой указатель на новый пакет. Модель-сторож не читает и не редактирует сами замечания.

При новом замечании, одобрении или изменении результата задача передаёт основному чату `01a1439c-0fdc-79d2-bce1-3968327bb807` путь к пакету с маркером `ReviewWatch:<batchId>`. Оператор прямо разрешил такую передачу. Параметры model/thinking при передаче не меняются: редактуру выполняет настроенная основная модель этого чата. Она продолжает проверку фактов, обязательную редакторскую вычитку и штатный цикл согласования. Изменённое содержание не публикуется без нового «Одобрить».

## Границы и защита

- Только текущие записи: карусель ffe75ad066f9ea5f; YouTube fda3e7578d62a698 и Instagram f07defb6acd90d31 по IMG_7925. Новые материалы добавляются в список наблюдения явно, не собираются из переписки.
- Локальное состояние: `content/reports/monitoring/review-watch.json`. Пакеты: `content/reports/monitoring/review-batches/`. Они вне очереди; очередь и журнал руками не меняются.
- Учтены уже обработанные замечания из прежнего `instagram-youtube.json`. Отметка доставки не означает, что редактор уже выполнил работу.
- `--begin=<batchId>` резервирует одну передачу. `--ack=<batchId>` допустим только после подтверждённой доставки. Неопределённый результат требует проверки маркера в целевом чате; слепого повтора нет.
- В пакет не копируются авторы, превью чужих записей, сырые ответы API, cookie и параметры доступа. Ключи использует штатный загрузчик; их значения не выводятся. Данные заявок/подписчиков/переписки не запрашиваются.
- Код не исправляет публикации, не запускает runner и не даёт разрешения deploy/restart, нового хранилища или расширения прав. Единственный исполнитель выпуска и все рубильники сохраняются.

## Расход и проверка

Вызов лёгкой модели раз в 5 минут остаётся. Экономия достигается отдельным коротким контекстом, низким уровнем рассуждения и вызовом основной модели только при событии. Нулевой расход токенов не обещается. Отдельного платного OpenAI API для этой схемы не подключали.

Локальный компьютер должен оставаться включённым, приложение — запущенным, проект — доступным. Держать основной чат открытым не требуется. Официальная документация: https://learn.chatgpt.com/docs/automations .
