# Telegram-пульт: следующий шаг владельца

Подготовлено 16.10.2026. Только рабочая группа, согласование и канал. Текст для передачи оператором; автоматически никому не отправляется.

## Короткая инструкция владельцу

1. На своём устройстве откройте управление каналом @ecopolis_kzn → «Администраторы». Проверьте точное имя бота: @EcopolisKZNbot. После отдельного согласования действия добавьте его администратором с правом публикации сообщений. Права администратора рабочей группы не дают права публикации в канале. Пароль и код входа никому не передавайте.
2. Утверждающим назначен владелец @CEO_ECOPOLIS_LLS (сообщение оператора 16.10.2026). Заместитель пока не указан. Для настройки нужен подтверждённый числовой Telegram ID владельца; имя, username и статус администратора группы его не заменяют. После установки команды основной S0 владелец отправляет `/myid@EcopolisKZNbot` в рабочей группе от своего личного аккаунта, без анонимного режима администратора. Бот отвечает номером в той же теме; владелец передаёт номер оператору. Команда сама не назначает права.
3. После настройки согласуйте с оператором одну конкретную проверку карточки: материал, тему, участника и ожидаемый результат. До этого не нажимайте «Продолжить выпуск» и не используйте /start_release: они снимают удержание выпуска. Тестовые сообщения без согласования не отправляются.

## Порядок для оператора

- Настройку APPROVER_IDS и включение TG_CHANNEL выполнять только после подтверждения владельца. Значения окружения не печатать; штатный перенос — tokens export/import. Изменения сервиса согласовать с основной инфраструктурной сессией.
- Сначала отдельно разрешённая проверка членства бота и can_post_messages без отправки публикации. Ошибка «member list is inaccessible» не доказывает наличие или отсутствие нужного права.
- Затем отдельно разрешённая карточка через штатные check → queue add → queue submit. Полный цикл требует решения назначенного человека; офлайн-тесты не заменяют его.
- Ручная выкладка проверяется отдельно: одобренная запись → пакет в теме «Выложить руками» в свой слот → фактическое размещение сотрудником → «Выложено». Статус «передано» не считать публикацией.
- HOLD оставить включённым до отдельного решения оператора; ALERTS_MUTED=1 не менять. Не запускать deploy, перезапуск, выпуск или изменение прав в рамках чтения этой инструкции.
