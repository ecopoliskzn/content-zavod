# Задачи на компьютере оператора

Три задачи планировщика Windows. Ставятся одной командой из корня проекта:

```bash
powershell -ExecutionPolicy Bypass -File ops\windows\install-tasks.ps1
```

| Задача | Когда | Что делает |
|---|---|---|
| `zavod-mirror` | каждые 15 минут | снимает копию очереди и журналов с сервера в `mirror/`, обновляет `mirror/РАСПИСАНИЕ.md`; если сервер молчит, шлёт тревогу в рабочую группу |
| `zavod-vault` | каждый день в 08:15 | пересобирает витрину Obsidian по свежей копии |
| `zavod-takeover` | каждые 5 минут, **выключена** | аварийный выпуск с компьютера. Включается только после перехвата расписания |

Журналы: `mirror\mirror.log`, `mirror\vault.log`, `mirror\takeover.log`.

## Что нужно знать

**Сервер главный, компьютер запасной.** Пока компьютер спит, его задачи не идут: копия стареет, сторож молчит. Расписание от этого не страдает, выпуск ведёт сервер. Проверьте в настройках электропитания, что компьютер не засыпает в рабочие часы, иначе тревога о молчащем сервере придёт с опозданием.

**Обёртки `.cmd` создаёт установщик.** В них зашит полный путь к `node.exe`: планировщик запускает задачи со своим `PATH`, и голое `node` там молча не находится. Переставили Node или перенесли проект в другую папку — запустите установщик ещё раз.

**Файлы `.cmd` и `.ps1` только латиницей.** Планировщик читает `.cmd` в кодировке OEM, PowerShell 5.1 читает `.ps1` без метки в ANSI. Кириллица в них превращается в мусор, и задача падает без внятной ошибки. У нас так однажды не вышли девять публикаций подряд.

## Перехват расписания

Порядок действий лежит в `docs/06-РАСПИСАНИЕ-И-ДУБЛЬ.md`. Коротко:

```bash
npm run mirror -- --takeover --yes
```

Затем включить задачу:

```bash
schtasks /Change /TN zavod-takeover /ENABLE
```

Когда сервер ожил:

```bash
npm run mirror -- --handback
```

```bash
schtasks /Change /TN zavod-takeover /DISABLE
```

## Снять задачи

```bash
powershell -ExecutionPolicy Bypass -File ops\windows\install-tasks.ps1 -Remove
```
