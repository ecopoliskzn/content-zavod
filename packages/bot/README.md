# Движок бота

Общая механика бота, перенесённая из прошлых проектов исполнителя и покрытая тестами. Завод её не переписывает: экземпляр для «Экополиса» собирается настройкой в `src/bot/instance.mjs`.

```bash
npm run test:bot
```

143 теста. Они идут отдельно от тестов завода (`npm test`): движок меняется редко и проверяется сам по себе.

## Что внутри

| Часть | Файл | Что делает |
|---|---|---|
| Подбор кодового слова | `src/ig/match.mjs` | точное совпадение, затем самая длинная подстрока; исключения; предел длины реплики |
| Сценарии | `src/ig/scenarios.mjs` | читает сценарии из каталога `bot/scenarios/` |
| Очередь событий Instagram | `src/ig/queue.mjs` | события складываются в файл и разбираются по одному; повтор события не даёт второго ответа |
| Отправка в Instagram | `src/ig/relay.mjs` | вызовы идут через релей |
| Приём событий | `src/ig/webhook.mjs` | проверка подписи, подтверждение подписки, разбор тела |
| Подписчики | `src/telegram/store.mjs` | журнал подписчиков бота со слиянием записей |
| Вход по ссылке | `src/telegram/entry.mjs` | разбор `/start <площадка>-<ключ>` |
| Тексты | `src/telegram/texts.mjs` | тексты экземпляра с подстановками |
| Отправка в Telegram | `src/telegram/relay.mjs` | вызовы идут через релей |
| Заявки | `src/leads.mjs` | заявка сначала пишется в файл, потом уходит дальше |
| Пульс | `src/heartbeat.mjs` | отметка каждого фонового цикла: когда шёл и когда шёл успешно |

Пути в таблице даны от каталога пакета.

Есть и части, которые завод «Экополиса» на старте не использует: цепочки сообщений, квиз, отчёт по подписчикам, клиент amoCRM. Они остаются в пакете, потому что покрыты тестами и понадобятся при подключении CRM клиента.

## Правила пакета

- **Пакет не читает окружение.** Адреса, ключи и пути передаёт приложение. Поэтому тесты не трогают настоящие ключи, а один процесс может держать несколько экземпляров.
- **Пакет не знает о клиенте.** Сценарии, тексты, материалы и каталог данных приходят настройкой.
- **Имена внутри русские.** Поля событий и функции названы по-русски (`подписьВерна`, `разобратьСобытия`, `положить`). Это не опечатка и перевода не требует.

## Когда его менять

Только с тестом на новое поведение и только если это нужно больше чем одному месту завода. Правка «под один случай» делается в `src/bot/`, а не здесь.
