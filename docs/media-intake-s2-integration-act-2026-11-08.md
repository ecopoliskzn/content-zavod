## Обязательные стыки до выкладки

1. S0 sync пока читает queueResults[channel]. ProtocolVersion 2 delivery записывает queueResults[channel:format]. Sync должен использовать точный target и targetEntryName; legacy одиночные квитанции сохраняются по channel. Нельзя объявить готовым многоформатный workflow до этой правки.
2. S0 runner ищет YouTube по имени. Когда у связанного видео многоформатный suffix и имя отличается, verify удерживает весь job. Нужна доказанная связь по material/точному job с тестом YouTube-first. Простая сортировка submit не заменяет защиту выпуска. До изменения runner не снимать этот отказ.
3. Новые protocolVersion 2 требуют approval.cardHash===contentHash для submitted. Legacy jobs допускают отсутствующий cardHash. Синтетический интеграционный transport в test/media-intake.test.mjs:173 создаёт только messageId; тест владельца нужно обновить до реального контракта cardHash, а не ослаблять delivery.
