# Грабли: на чём мы уже обжигались

Опыт двух запусков: собственного завода исполнителя (kormishin.ru) и прошлого запуска для клиента (сентябрь–октябрь 2026). У каждой записи есть цена: потерянный день, невышедшая публикация или сообщение, ушедшее не тому человеку. В коде завода эти уроки уже учтены; здесь они записаны, чтобы никто не «упростил» обратно.

Формат записи нужен сборщику витрины Obsidian: заголовок третьего уровня, затем строки «Где» и «Откуда».

## Instagram

### Личный аккаунт к API не подключается вообще
Где: instagram, tokens
Откуда: прошлый запуск для клиента
Программный доступ есть только у профессионального аккаунта: «компания» или «автор». Личный аккаунт не подключить никаким способом. Это проверяется первым шагом, до выдачи доступов: владелец открывает настройки и переключает тип. Подписчики и публикации при этом сохраняются.

### Комментарий с кодовым словом не дошёл до сервера
Где: instagram, bot
Откуда: прошлый запуск для клиента
Аккаунт был подключён к чужому приложению Meta в роли тестировщика. Сообщения в директ приходили, а событие о комментарии под публикацией нет. Событиям о комментариях Meta может требовать расширенный доступ приложения. В заводе на этот случай есть опрос: раз в пять минут сервер сам читает новые комментарии (`IG_POLL=1`). Проверяется в первый же день живым комментарием с чужого аккаунта.

### Подписка на события слетает при продлении маркера
Где: instagram, tokens
Откуда: kormishin.ru
Маркер жив, вебхук настроен, а кодовые слова молчат. Причина: подписка аккаунта на события оформляется отдельным вызовом и пропадает при перевыпуске маркера. Продление в заводе сразу оформляет подписку заново и поднимает тревогу, если она не оформилась.

### Бот ответил в чужой разговор
Где: bot, instagram
Откуда: kormishin.ru
Кодовое слово искали вхождением в текст без предела длины. Пять раз бот ответил людям, которые просто употребили это слово в длинной реплике. Теперь слово должно стоять отдельно, а у сценария есть предел длины сообщения (`максДлина`): длинная реплика со словом внутри считается разговором.

### Своё сообщение приходит обратно как входящее
Где: bot, instagram
Откуда: kormishin.ru
Сообщение, которое отправил сам бот, Meta присылает на вебхук как новое событие. Без отсечки бот отвечает сам себе по кругу. Событие, где отправитель равен своему аккаунту, отбрасывается при разборе.

### Вебхук, ответивший не 200, отключают
Где: server, instagram
Откуда: kormishin.ru
По любому коду, кроме 200, Meta повторяет событие всё чаще, а после нескольких неудач снимает подписку целиком. Сервер отвечает 200 сразу после проверки подписи, а обработку ведёт после ответа. Ошибка разбора остаётся нашей заботой, а не поводом получать одно событие сутки подряд.

### Два ответа одному человеку
Где: bot
Откуда: kormishin.ru
Сначала отправили ответ, потом записали, что ответили. Между этими шагами процесс упал, и при повторе человек получил ответ второй раз. Запись в журнал делается до отправки: лучше промолчать, чем написать дважды.

### Подпись вышедшего рилса программой не исправить
Где: instagram
Откуда: kormishin.ru
Опечатку в подписи опубликованного поста API править не умеет, только руками в приложении. Поэтому подпись согласуется до выхода и проверяется дважды.

### Ролик с телефона площадка отвергла
Где: instagram, storage
Откуда: документация Meta, проверено на kormishin.ru
Исходник 2160×3840 не проходит: ширина видео для рилса до 1920. Под Instagram готовится копия 1080×1920. Загрузчик завода проверяет ширину, длину и кодек до отправки, а не через десять минут обработки на площадке.

### С сайта Meta файл не берёт
Где: instagram, threads, storage
Откуда: kormishin.ru
Картинку и ролик Meta забирает сама по адресу, и с российских сайтов возвращает «Media download has failed». Из публичного объектного хранилища берёт. Между попытками нужна минута, попыток до восьми.

### Вход в аккаунт клиента со своего устройства
Где: instagram, tokens
Откуда: kormishin.ru, 27.09.2026
Попытка автоматизировать действия под входом владельца закончилась разлогином и проверкой аккаунта. В аккаунт клиента мы не входим никогда: владелец сам входит на своём телефоне и выдаёт ключ.

### Личный ответ на комментарий можно отправить один раз
Где: bot, instagram
Откуда: документация Meta
На комментарий бот может ответить лично одним сообщением и в течение семи суток. Дальше писать человеку можно только в сутки после его последнего сообщения. Поэтому в первом же сообщении лежит всё нужное: материал и ссылка.

## Threads

### Параметры JSON-ом площадка молча теряет

Где: threads

Между созданием контейнера и публикацией нужна пауза: три секунды для текста, двадцать пять для картинки. Без неё площадка отвечает, что ресурса нет.

### Ссылку на сайт площадка отклонила

Откуда: прошлый запуск для клиента
Реплику со ссылкой на сайт Threads не принял (ошибка 4279047). Ссылка ставится одна и только в последней реплике; если площадка её отклоняет, ветка выходит без ссылки, а ссылка живёт в профиле.

### Ветка работает вдвое лучше одиночного поста

Откуда: прошлый запуск для клиента
Медиана просмотров у веток из двух и более реплик 170, у одиночных постов 86. Одиночный пост завод пропускает с замечанием.

### Утренние слоты слабее вечерних

Слоты 19–21 дали медиану 196 просмотров, слоты 11–13 дали 69. Сетка правится по цифрам недельного отчёта, а не на глаз.

### Вопрос в первой фразе не работает
Где: threads
Откуда: прошлый запуск для клиента
Из девятнадцати зачинов-вопросов сработал один. Зачин с героем, цифрой или названной компанией сильнее. Проверка речи отмечает вопрос в первой фразе замечанием.

### Пропущенный день стоит дороже слабого поста
Где: threads, queue
Откуда: прошлый запуск для клиента
После дня без публикаций охват следующих веток падал. Поэтому в очереди всегда есть запас одобренного на три дня вперёд.

### Четыре ветки вышли за пять минут
Где: queue, threads
Откуда: kormishin.ru
После простоя выпуск разом отправил всё накопившееся. Площадка режет охват такой пачке. Теперь опоздавшие идут по одной раз в сорок минут и не ночью, а опоздавшие больше чем на шесть часов не выходят вовсе.

### Частое чтение закрыло доступ
Где: threads, metrics
Откуда: kormishin.ru, 07.10.2026
Сервер слишком часто читал обсуждения, и площадка закрыла ему доступ кодом 80016 на несколько часов. Цифры снимаются раз в сутки.

### Видео в Threads не расходится
Где: threads
Откуда: kormishin.ru
Ролики в Threads получают охват на порядок ниже текста. Формат площадки: текстовая ветка, иногда с одной картинкой.

### Кодовое слово в Threads некому услышать
Где: threads, bot, gates
Откуда: kormishin.ru
Кодовые слова работают в Instagram. В Threads на такое слово никто не ответит, и человек останется без материала. Проверка речи не пропускает слово бота в ветку.

Запись со строкой «[здесь ваш текст]» была одобрена и вышла во ВКонтакте и Telegram. Одной проверки на входе оказалось мало: готовность проверяется и перед самым выпуском.

### Новая проверка сняла шесть одобренных постов
Где: gates, queue
Откуда: kormishin.ru, 25.09.2026
Только что добавленная проверка фактов за день остановила шесть публикаций, и ни одна не была плохой. Перед выпуском останавливают только готовность и реклама. Речь и факты проверяются при постановке, когда рядом оператор.

### Пост про завтра вышел послезавтра
Где: queue
Откуда: kormishin.ru
Запись, опоздавшая из-за простоя, вышла с текстом «завтра в 10:00» на день позже события. Запись, опоздавшая больше чем на шесть часов, не выходит: человеку уходит кнопка «в ближайший слот» или «снять».

### Компьютер уснул, и расписание встало
Где: operator, queue
Откуда: kormishin.ru, 03.10.2026
Пока выпуск жил в планировщике Windows, сон компьютера означал пропущенные публикации. Расписание держит сервер. Компьютер оператора хранит копию и сторожит сервер.

### Девять публикаций не вышли из-за кириллицы
Где: operator
Откуда: kormishin.ru
Планировщик Windows читает `.cmd` в своей кодировке и русские имена флагов превращает в мусор. Задача завершалась без внятной ошибки. Флаги, имена файлов кода и содержимое `.cmd` только латиницей.

### Планировщик не нашёл node
Где: operator
Откуда: kormishin.ru
У планировщика свой `PATH`, и голое `node` в нём не находится. В обёртках задач стоит полный путь к `node.exe`.

### Код 127 при сделанной работе
Где: queue, operator
Откуда: kormishin.ru
Мгновенный `process.exit()` после сетевого запроса на свежем Node под Windows давал ложный код 127. Код выхода выставляется полем `process.exitCode`.

### Провал выкладки выглядел успехом
Где: operator, server
Откуда: kormishin.ru
Вывод выкладки пустили через пайп, и он съел код выхода. Скрипт выкладки нельзя запускать через `| tee` и `| tail`.

### Проверка месяц молча не работала
Где: gates
Откуда: kormishin.ru
Граница слова `\b` в JavaScript не видит кириллицу. Правила с ней не срабатывали ни разу, и никто этого не заметил. Границы считаются через `\p{L}`, а у каждого правила есть тест с текстом, на котором оно обязано сработать.

### Отказ по правилу приняли за поломку
Где: queue, operator
Откуда: kormishin.ru
Команда возвращала один и тот же код и на «проверки не пройдены», и на «нет сети». Оператор чинил сервер там, где ему просто отказали. Код 1 означает отказ по правилу, код 2 означает поломку.
