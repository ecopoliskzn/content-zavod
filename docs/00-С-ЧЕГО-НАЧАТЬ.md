# С чего начать

Порядок первого дня для оператора. Что в папке, что проверить до встречи с клиентом, как открыть первую сессию.

## 1. Что в папке

```text
ecopolis-zavod/
├── МАСТЕР-ПРОМПТ.md      общий план: решения, площадки, сессии, команды
├── AGENTS.md             правила, которые Codex читает сам в каждой сессии
├── zavod.config.json     реестр: площадки, слоты, сессии, расписания
├── .env.example          образец файла окружения: имена ключей, без значений
├── docs/                 двенадцать документов, от брифа до витрины
├── prompts/
│   ├── sessions/         промпты восьми сессий Codex
│   └── samples/          образцы на каждый вид работы и готовые записи
├── legal/                документы для юриста клиента
├── content/              статьи сайта, банк тем, канал YouTube, серии
├── bot/                  кодовые слова, материалы, тексты бота, ссылки, формы
├── src/                  код завода
├── packages/bot/         движок бота из прошлых проектов
├── ops/                  сервер, релей, расписание, выкладка, задачи Windows
├── test/                 тесты
└── .agents/, .codex/     навыки и настройки Codex
```

## 2. Проверить, что папка жива

Нужен Node 20 или новее. Зависимостей нет: `npm install` не запускается.

```bash
npm test
```

```bash
npm run test:bot
```

```bash
npm run doctor
```

Тесты зелёные. Доктор покажет красные строки про ключи и адреса: это ожидаемо, их пока нет. Он же скажет, что приём заявок закрыт до утверждения текстов согласий: так и должно быть.

```bash
npm run vault -- --check
```

Витрина собирается и без сервера: «висячих ссылок 0».

## 4. До встречи с клиентом

Можно сделать уже сейчас, ничего от клиента не требуя.

- [ ] Собрать витрину и открыть её в Obsidian: `npm run vault`, затем «Открыть папку как хранилище» → `vault`. Её можно показать на встрече: как устроен завод, который клиент получит.
- [ ] Просмотреть `content/youtube/channel.json` глазами: у клиента 243 ролика, и несколько из них обгоняли обычные в десятки раз. С этого удобно начинать разговор.
- [ ] Прочитать `legal/00-ПАМЯТКА-ЮРИСТУ.md`. Завод ведёт клиент, поэтому исполнитель в согласии не называется; реквизиты исполнителя вписываются только в акт (`legal/04`) и в раздел 7 `legal/06`.
- [ ] Решить, кто из людей клиента будет утверждающим. Без этого завод не стартует.

## 5. Встреча с клиентом

По `docs/01-БРИФ-КЛИЕНТА.md`. Четыре вещи, без которых нельзя уходить:

1. **Имя утверждающего и его заместителя.** Человек, который каждый день нажимает «Одобрить».
2. **Имя ответственного за заявки.**
3. **Кто владеет аккаунтами** и когда он на связи для входов.
4. **Одна версия по спорным цифрам**, хотя бы срок: когда технолог ответит.

Юристу уходит папка `legal/`. Тому, кто управляет кабинетом Timeweb и доменом, таблица из раздела 0 в `ops/СЕРВЕР.md`.

Ответы вписываются в конец `docs/01-БРИФ-КЛИЕНТА.md`: этот файл читает каждая сессия.

## 6. Первая сессия Codex

Новый тред в Codex, рабочий каталог — эта папка. Первое сообщение:

```text
Сессия S0.
```

Codex подгрузит правила из `AGENTS.md` и навык сессии. Если навык не сработал:

```text
Прочитай prompts/sessions/S0-ФУНДАМЕНТ.md и работай по нему.
```

Сессия S0 ведёт по шагам от серверов до первой тестовой записи на каждой площадке.

Параллельно, в отдельных тредах, можно открыть две сессии. Сервера и ключей площадок у них на этом шаге ещё нет, и часть их работы от этого не зависит:

- **S4** разбирает оставшиеся статьи сайта в банк тем. Статьи уже лежат в `content/articles/`. Команды, которые ходят на сервер (`npm run mirror`, `npm run queue -- news`), сессия пока пропускает: ящика новостей ещё нет;
- **S2** готовит список серий по существующим роликам канала и вопросы оператору о содержании роликов. Опись канала уже лежит в `content/youtube/channel.json` (снята 10.10.2026). Команду `npm run yt -- --channel` сессия пропускает, пока нет ключа YouTube.

Скажи это в первом сообщении треда, чтобы сессия не упёрлась в первую же команду:

```text
Сессия S4. Сервера ещё нет: работай только со статьями из content/articles, команды к серверу пропускай.
```

```text
Сессия S2. Ключей YouTube ещё нет: работай по сохранённой описи content/youtube/channel.json, ничего на канал не отправляй.
```

## 7. Как устроен обычный день после запуска

| Когда | Кто | Что |
|---|---|---|
| 7:30 | сервер | план дня в рабочую группу: что выйдет, что ждёт «да» |
| утро | оператор, сессии S1 и S2 | правки утверждающего, затем новое; запас на три дня вперёд |
| 8:00, 15:00 | сервер, сессия S6 | сводка комментариев, черновики ответов |
| день | утверждающий | один заход: пять–десять карточек, десять минут |
| в слоты | сервер | выпуск одобренного |
| 22:00 | сервер | итог дня: что вышло, что нет, что завтра |
| понедельник | сервер, сессия S5 | недельный отчёт и разбор: не больше трёх решений |

Оператору на завод в обычный день нужен час–полтора: большую часть времени занимает видео.

## 8. Что на компьютере оператора

- Файл окружения `.env.local` в корне проекта. В git не попадает. Имена ключей: `.env.example`.
- Три задачи планировщика Windows: копия с сервера, витрина, аварийный выпуск (выключен). Ставятся одной командой: `ops/windows/README.md`.
- Ролики-исходники на диске, вне проекта.
- Каталог `reference/`: образцы кода из прошлых проектов. В git, на сервер и клиенту не уезжает.

Компьютер в рабочие часы не засыпает: иначе сторож, который следит за сервером, молчит вместе с ним.

## 9. Что честно сказать клиенту на старте

- Ни одна публикация не выйдет без его «Одобрить».
- Первый месяц Instagram и Threads работают через приложение исполнителя. Через месяц переезд на своё, и это его работа на два–три часа. До переезда кодовое слово в директе не отвечает: слово пишут в комментарии.
- Завод ведёт его сотрудник. Исполнитель ставит завод и учит оператора, а к заявкам и подписчикам доступа не получает.
- Бот и формы заявок включатся после того, как его юрист утвердит тексты согласий, а компания подтвердит, что уведомления в Роскомнадзор поданы. До этого публикации ведут на статьи сайта, без кодовых слов и ссылок в бота.
- Часть кода не проверена боем: публикация рилсов, Rutube, фото и видео во ВКонтакте, снятие срока выхода с ролика YouTube при отзыве согласия. По каждой есть ручной запасной путь. Список: `МАСТЕР-ПРОМПТ.md`, раздел 10.
- Дзен, Rutube и видео во ВКонтакте на старте выкладывает его сотрудник: завод присылает готовый текст и файл, человек вставляет и нажимает «Выложено». Пока кнопка не нажата, завод не считает материал вышедшим.
- Завод не видит звонков, заявок с форм его сайта и договоров. Об этом мы будем спрашивать раз в неделю.
- Своё видео нужно каждую неделю: десять–пятнадцать коротких кадров с объекта. Без него YouTube встанет после того, как кончатся серии на старых роликах.
