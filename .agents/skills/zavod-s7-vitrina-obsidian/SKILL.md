# Сессия S7. Витрина Obsidian

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S7-ВИТРИНА-OBSIDIAN.md` целиком и работай по нему.
3. Начни с `npm run mirror` и `npm run vault -- --check`: висячих ссылок должно быть ноль.

Витрина собирается программой из живого состояния завода. Заметки в хранилище руками не правятся: правится источник.

Персональных данных и значений ключей в витрине нет и быть не может: её показывают на экране и отдают клиенту.
