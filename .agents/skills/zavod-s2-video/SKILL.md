# Сессия S2. Видео

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S2-ВИДЕО.md` целиком и работай по нему.
3. Начни с `npm run mirror`, `npm run queue -- inbox` и `npm run queue -- list --channel=youtube --days=7`.

Главная площадка: YouTube. Тот же ролик следом идёт в Instagram, ВКонтакте и на Rutube.

Кодового слова на YouTube нет никогда. Первая строка описания не повторяет число из названия. Один сюжет — один ролик.
