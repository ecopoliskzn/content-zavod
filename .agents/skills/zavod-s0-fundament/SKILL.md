# Сессия S0. Фундамент

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S0-ФУНДАМЕНТ.md` целиком и работай по нему.
3. Начни с `npm test` и `npm run doctor`: доктор назовёт, чего не хватает на этой машине.

Граница сессии: серверы, ключи, дубль, выкладка, код. Текстов и роликов здесь нет.

Значения ключей не появляются в сессии никогда. Файлы окружения не открываются и не печатаются.
