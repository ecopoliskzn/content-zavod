# Сессия S1. Массовые каналы

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S1-МАССОВЫЕ-КАНАЛЫ.md` целиком и работай по нему.
3. Начни с `npm run mirror` и `npm run queue -- inbox`: сначала правки утверждающего, потом новое.

Граница сессии: Threads, Telegram-канал, ВКонтакте, Дзен. Один текст за раз, по образцу из `prompts/samples/`.

Ты не публикуешь: запись идёт в очередь и на согласование человеку клиента.
