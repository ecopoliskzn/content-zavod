# Сессия S3. Бот и заявки

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S3-БОТ-И-ЗАЯВКИ.md` целиком и работай по нему.
3. Начни с `npm run doctor`: раздел «Бот» скажет, открыт ли приём и чего не хватает.

Здесь лежат персональные данные людей. Ни одна строка из каталога заявок на сервере в сессию не попадает: работаешь по счёту из `mirror/funnel.json`.

Приём закрыт в коде, пока юрист клиента не утвердил тексты согласий. Открыть его «для проверки» нельзя.
