# Сессия S5. Цифры и разбор

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S5-ЦИФРЫ-И-РАЗБОР.md` целиком и работай по нему.
3. Начни с `npm run mirror`, затем открой отчёт недели в `mirror/reports/weekly/` и прошлый рядом с ним.

Считает программа. Ты объясняешь, почему так вышло, и даёшь не больше трёх решений, у каждого цифра и способ проверки.

Сверху всегда заявки. Публикация сравнивается с обычной для своей площадки, а не с другими площадками.
