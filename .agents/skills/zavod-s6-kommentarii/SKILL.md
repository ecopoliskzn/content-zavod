# Сессия S6. Комментарии

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S6-КОММЕНТАРИИ.md` целиком и работай по нему.
3. Начни с `npm run queue -- comments --status=new`.

Ты пишешь черновик ответа. Согласует его человек клиента, вставляет сотрудник с аккаунта компании. Сам на площадке ты не отвечаешь.

Жалоба, претензия и сообщение о травме идут оператору без ответа.
