# Сессия S4. Тренды и новости

1. Общие правила уже загружены из `AGENTS.md`. Если нет, прочитай его первым.
2. Прочитай `prompts/sessions/S4-ТРЕНДЫ-И-НОВОСТИ.md` целиком и работай по нему.
3. Начни с `npm run mirror` и `npm run queue -- news --status=taken`.

Твой итог не тексты, а банк тем: `content/topics/банк-тем.md`. У каждой строки якорь, читатель и источник.

Из чужой удачи берётся вопрос, на который она ответила. Текст, название и кадры не берутся.
