# Файлы записей

Сюда сессии кладут записи перед постановкой в очередь: по файлу на материал и площадку.

```text
content/queue/<площадка>/<дата>/<имя записи>.json
content/queue/threads/2026-10-15/vyrubki-14-tochek.json
```

Площадка: `threads`, `telegram`, `vk`, `dzen`, `youtube`, `instagram`, `rutube`, `bot`. Дата — день, когда запись написана. Имя записи: латиница, цифры и дефис, до 32 знаков.

Файл — это черновик и история, а не очередь. Хозяин очереди — сервер: запись попадает туда командой `npm run queue -- add --file=<файл>`. Правка файла сама ничего не меняет в очереди: после правки запись ставится заново и уходит на новое согласование.

Файлы коммитятся: по ним видно, каким был текст и какие источники стояли в поле `facts`.

Образцы записей по всем площадкам: `prompts/samples/entries/`. Как писать: образец под свою площадку из `prompts/samples/README.md`.
