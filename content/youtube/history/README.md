# Память о правках описаний на канале

Сюда программа кладёт по файлу на ролик, описание которого она меняла: `<номер ролика>.json`.

| Поле | Что в нём |
|---|---|
| `first` | описание, каким оно было до первой правки завода. Не перезаписывается |
| `block` | блок ссылок, который завод дописал в конец последним |
| `at` | когда была последняя правка |

Зачем это нужно. Описания старых роликов писал клиент. Завод дописывает в конец блок ссылок на серию и соседние ролики и при следующем запуске убирает ровно тот блок, который поставил сам. Строку «Смотрите также: …», которую клиент когда-то написал своей рукой, он своей не считает.

Вернуть ролику описание, каким оно было до завода:

```bash
npm run yt -- --restore --video=<номер ролика>
```

Файлы коммитятся вместе с `content/youtube/series.json`: правка чужого канала делается только с возможностью вернуть всё как было.
