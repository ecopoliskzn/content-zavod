# Электровал «Прохоров» для укладки резиновых покрытий

Один из важных этапов устройства покрытия — равномерное уплотнение и формирование поверхности после распределения рабочей смеси.

Для решения этой задачи компания «ЭКОПОЛИС» разработала электровал «Прохоров» — профессиональное оборудование для укладки и уплотнения резиновых покрытий .
